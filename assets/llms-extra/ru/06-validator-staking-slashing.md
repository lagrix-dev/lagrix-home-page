# 6. Залоги супер-узлов: простой и мошенничество

Супер-узлы — опора Lagrix: они хранят таблицу обнаружения, строят поисковую выдачу, ведут индекс чеков и отзывов и помогают агентам
соединиться; сам расчёт выполняет контракт эскроу (документ 04). Контракт SuperNodeDeposits.sol связывает поведение сервера в сети с
залогом его оператора. Главное правило этого документа: **простой — не мошенничество**. Сервер, который ушёл из сети, просто перестаёт
зарабатывать; монеты забирают только за доказанное мошенничество.

## 6.1 Залог

Залог одинаков для всех операторов (документ 05, раздел 5.6; журнал, запись 31). Кто уже держит заработанные монеты, блокирует их; у
кого их нет, первые награды остаются заблокированными как залог, пока он не достигнет нужного размера, а штрафы берутся из накопленного.
При выводе залог остаётся заблокированным 14 дней: если за это время вскроется мошенничество, совершённое до вывода, штраф ещё можно
взыскать.

```solidity
struct SuperNode {
    uint96 stakeBalance;    // заблокированный залог в LGX
    uint40 lastSeen;        // последняя подтверждённая доступность
    uint40 unbondingFrom;   // начало 14-дневного вывода (0, если вывода нет)
    uint16 slashCount;      // число доказанных нарушений
    bool   blacklisted;     // исключён навсегда за подделку
    address pubKeyAddress;  // адрес, привязанный к NodeID
}
```

## 6.2 Простой — не мошенничество

Как в биткоине, где выключенный майнер просто не находит блоков, супер-узел за простой не наказывается.

- **Пока узел недоступен,** он не обслуживает сделок, поэтому не получает ни чеков, ни доли награды периода; он не проходит минимум
  качества периода, поэтому не получает ни равной доли награды, ни доли котла комиссий периода. Он теряет только доход.
- **Доступность** измеряют соседние узлы: регулярными проверками (PING) из таблицы Kademlia (документ 01).
- **Если узел недоступен 30 дней подряд или не проходит минимум качества несколько периодов,** его удаляют. Его место открывается на
  условиях дня, когда оно открылось (документ 05, раздел 5.6), а залог возвращается оператору после 14-дневного вывода. Он не обманывал —
  он ушёл.
- **Уход по ротации или при перегрузке — тоже не наказание.** Залог возвращается так же; правила — в документе 05, раздел 5.6.

## 6.3 Мошенничество и его доказательство

Блокчейн не видит IP-пакетов, поэтому мошенничество доказывается чеками и проверками, которые может повторить любой.

**Отбрасывание пакетов.** Заказчик (агент A) отправляет трафик исполнителю (агенту B) через супер-узел R. Агент A подписывает пакет;
агент B подписывает квитанцию о доставке. Если R принял пакет для передачи, а квитанции B нет, агент A отправляет `TRACE_REQUEST`; три
независимых соседа подтверждают, что R принял пакет и не передал его, — так складывается Fraud Proof.

**Подделанная выдача.** Место, которое выдаётся по очереди, считается проверяемо (документ 17, раздел 17.3). Выдача, в которой это место
не совпадает с расчётом, — готовое доказательство: контракт проверяет подпись супер-узла на ней и данные расчёта.

**Поддельные таблицы и захват NodeID.** Попытка подделать записи Kademlia DHT или выдать себя за другой узел доказывается подписями,
которые не совпадают с ключом узла.

## 6.4 Наказания

| Нарушение | Доказательство | Наказание |
|---|---|---|
| Простой | недоступность для соседей | **нет**; узел теряет доход и через 30 дней удаляется с возвратом залога |
| Отбрасывание пакетов | Fraud Proof с отсутствующей квитанцией | 10 % залога |
| Подделанная выдача | выдача, не совпадающая с проверяемым расчётом | 25 % залога |
| Поддельные таблицы, захват NodeID | несовпадающие подписи | 100 % залога и исключение навсегда |

**Куда идут изъятые монеты.** Половина — тому, кто доказал нарушение: награда за то, что держит сеть честной. Другая половина навсегда
выводится из обращения — как в биткоине, где невостребованная награда просто теряется. Новые монеты взамен не выпускаются, поэтому
итоговое число монет оказывается меньше 1 000 000 000 ровно на эту величину.

```
[Агент-заказчик] --(пакет)--> [Супер-узел R] --X (отброшен)--> [Агент-исполнитель]
       |                                                              |
       +---------------- (TRACE_REQUEST, ожидание квитанции) ---------+
                                      |
                              [Fraud Proof]
                                      |
                                      v
                       [SuperNodeDeposits.sol: slashSuperNode()]
                                      |
                    +-----------------+-----------------+
                    |                                   |
          (50 % тому, кто доказал)          (50 % выводится из обращения)
```

## 6.5 Защита от ложных доносов

Чтобы контракт не заваливали ложными доказательствами, вызов `slashSuperNode()` требует от заявителя заблокировать небольшой залог.

- **Доказательство верное:** заявитель получает залог обратно и половину штрафа.
- **Доказательство ложное:** залог заявителя выводится из обращения.

Честная работа приносит больше, чем риск залогом, а ложный донос стоит дороже молчания.
