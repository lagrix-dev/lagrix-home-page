# 9. Комиссия сделки: доход супер-узлов, которые не обслуживали эту сделку

С каждой сделки сеть берёт комиссию. Этот документ описывает, в какой валюте она берётся, какова её ставка, куда уходит и почему. Монета
$LGX в этом механизме не участвует: комиссия — это деньги за работу сети, а $LGX — актив своего держателя и залог супер-узла (документ 05).

## 9.1 Валюта: USDC

Агенты платят друг другу за работу в USDC (документ 04). Комиссия берётся в той же валюте и выплачивается в ней же.

| Почему USDC | Что это даёт |
|---|---|
| Комиссия стоит реальных денег с первого дня | фальшивая сделка с самим собой стоит 5 % её суммы, даже пока $LGX ещё не существует |
| Выплаты понятны людям | «пришло 10 центов» — без пересчёта по курсу |
| Доход супер-узлов не зависит от курса | когда выпуск угаснет, у операторов остаётся стабильный доход |
| Внутри механизма нет торговли монетой | сеть не покупает и не продаёт $LGX и не влияет на её цену |

## 9.2 Ставка и момент удержания

Ставка — **5 % от суммы сделки, константа в неизменяемом коде**. Изменить её не может никто; другая ставка может прийти только с новой
версией контрактов, на которую участники переходят добровольно (документ 18). Эскроу-контракт удерживает комиссию, когда сделка переходит
в состояние COMPLETED (документ 04). Если сделка закончилась возвратом (REFUNDED), комиссия не берётся.

Комиссия берётся с самой первой сделки, в том числе во время разогрева до начала выпуска (документ 05, раздел 5.2).

## 9.3 Куда уходит комиссия

Каждая комиссия делится **поровну между всеми активными супер-узлами, кроме того, через который прошла сделка**. Если других супер-узлов
ещё нет, комиссия копится в контракте и делится между супер-узлами, которые войдут позже.

```solidity
// Набросок: комиссия сделки зачисляется равными долями каждому активному супер-узлу, кроме обслужившего её
function _creditFee(uint256 fee, address servingNode) internal {
    uint256 others = activeNodes - (isActive[servingNode] ? 1 : 0);
    if (others == 0) { reserve += fee; return; }       // других узлов нет: копится для тех, кто войдёт позже
    accPerNode += fee / others;                          // доля каждого узла растёт на равную часть
    excluded[servingNode] += fee / others;               // ...кроме узла, обслужившего эту сделку
}

// Вошедший супер-узел начинает с текущей суммы: paid[node] = accPerNode, и получает свою часть `reserve`.
function claim() external {
    uint256 a = accPerNode - paid[msg.sender] - excluded[msg.sender];
    paid[msg.sender] += a;
    usdc.safeTransfer(msg.sender, a);
}
```

Контракт хранит одну накопленную сумму, поэтому стоимость сделки одинакова при любом числе супер-узлов. Деньги не переводятся на каждой
сделке: каждый супер-узел выводит накопленное одной операцией, когда захочет.

## 9.4 Почему так

Комиссия защищает от фальшивых сделок, только если уходит тем, кем нападающий не может дёшево стать, и долями, которые он не может
увеличить.

- **Стать супер-узлом дорого:** приведённые участники, проверенные в течение месяца, залог (документ 05, раздел 5.6).
- **Равная доля на узел не растёт от фальшивого оборота.** Супер-узел, гоняющий фальшивые сделки через себя, не получает назад ничего из
  своей комиссии. Группа, у которой k супер-узлов из M и которая гонит фальшивые сделки через один из них, получает назад не больше
  (k−1)/(M−1) этой комиссии, и каждый из этих узлов стоит полного входа.
- **Исключение обслужившего узла важнее всего на старте.** Без него первый и единственный супер-узел получал бы свою комиссию назад
  целиком и мог бы забирать награду бесплатно.
- **Одна ставка для всех.** Если бы каждый супер-узел назначал свою ставку, комиссия всё равно уходила бы другим узлам, поэтому каждому
  узлу выгодно было бы только снижать ставку — до нуля, где фальшивые сделки ничего не стоят.

## 9.5 Как об этом говорить

Комиссия — доход супер-узлов, которые держат сеть, оплачиваемый каждой сделкой и делимый между ними поровну. Сумма, которую получит
супер-узел, заранее не известна и ничем не гарантирована: она зависит от того, какие сделки закрываются в сети.
