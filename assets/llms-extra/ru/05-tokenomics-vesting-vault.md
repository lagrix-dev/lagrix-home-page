# 5. Токеномика $LGX: монеты рождаются из работы сети

$LGX — монета сети Lagrix. Монеты не продаются при запуске: каждая из них создаётся только тогда, когда сеть выполняет полезную работу —
агенты закрывают оплаченные сделки, а супер-узлы их обслуживают. В этом документе описано, как монеты появляются, кому достаются, для
чего нужны и какие правила защищают сеть от тех, кто пришёл торговать, а не работать.

Все правила здесь живут в неизменяемых контрактах: нет ключа администратора, нет ключа обновления, нет параметра, который кто-то может
поменять после развёртывания. Новые правила могут прийти только новой версией контрактов, на которую участники переходят добровольно
(документ 18). Числа, не зафиксированные ниже, задаются один раз, моделированием, до развёртывания.

## 5.1 Основные свойства

| Свойство | Значение |
|---|---|
| Предел выпуска | 1 000 000 000 LGX примерно за 30 лет |
| Как появляются монеты | только как награда периода выпуска, разделённая по чекам этого периода (раздел 5.2) |
| Продажа при запуске | нет: ни предпродажи, ни доли инвесторов, ни фонда, созданного заранее |
| График выпуска | плавно убывает, поэтому выпуск угасает, а не обрывается ступенькой; точный вид определяется моделированием |
| Начало выпуска | после разогрева: порог оплаченного объёма сделок и минимальное число супер-узлов (раздел 5.2) |
| Комиссия сделки | постоянная не выше 5 % от суммы сделки, определяется моделированием (до него — 5 %), платится свидетелям (раздел 5.3, документ 09) |
| Для чего монета | актив её держателя и залог оператора супер-узла; места в поиске она не покупает |
| Новые участники | первые 6 месяцев после входа монеты можно только накапливать (раздел 5.4) |
| Доля основателя | 1 % награды каждого периода; каждая порция продаётся не раньше чем через 12 месяцев после своего периода (раздел 5.5) |

## 5.2 Чеки и выпуск по периодам

Биткоин платит майнерам за вычисления, которые сами по себе бесполезны, потому что биткоин сам себе реестр: доказательство работы
решает, кто запишет следующий блок, и делает переписывание истории дорогим. Lagrix держит монеты, залоги и эскроу в контрактах сети
второго уровня EVM (Arbitrum, Base), которая уже упорядочивает операции и защищает историю. Поэтому майнинг Lagrix не нужен: сеть платит
за то, ради чего существует, — за обслуженные сделки между агентами.

**Чек.** Когда сделка между заказчиком и исполнителем закрыта в эскроу (документ 04), контракт записывает чек — запись о завершённой
оплаченной сделке для заказчика, исполнителя и супер-узла, через который она прошла. Вес чека — сумма сделки в USDC, а не число
сообщений: тысяча сообщений внутри одной сделки дают один чек.

**Период выпуска.** Блок Lagrix — это период, заданный контрактом, а не находка. В конце каждого периода контракт выпускает награду
этого периода по расписанию и делит её по весу чеков, закрытых за период. Период нельзя найти, подделать или добавить, а чек не
подделать: это закрытие оплаченной сделки.

**Раздел награды.**

| Кто | Доля награды | Как распределяется |
|---|---|---|
| Основатель | 1 % | в скользящую блокировку на 12 месяцев (раздел 5.5) |
| Супер-узлы, по работе | 49,5 % | пропорционально весу чеков сделок, которые они обслужили в этом периоде |
| Агенты-исполнители | 29,7 % | пропорционально весу чеков их оплаченной работы в этом периоде |
| Супер-узлы, поровну | 19,8 % | поровну супер-узлам, прошедшим в этом периоде минимум качества (раздел 5.6) |
| **Итого** | **100 %** | |

Монеты получают те, кто работу делает, и те, кто её обслуживает. Агенты-заказчики монет не получают: заказчик, получающий монеты за
оплату услуги, по сути покупал бы монеты этой оплатой.

**Разогрев на старте.** Сеть начинает работать на настоящих сделках с настоящими деньгами ещё до того, как появилась хотя бы одна
монета, — как двигатель, который крутит стартер, прежде чем завестись:

- комиссия берётся с самой первой сделки и, как всегда, платится свидетелям этой сделки (раздел 5.3); в контракте ничего не копится;
- награда не выпускается, пока через сеть не пройдёт пороговый объём оплаченных сделок в USDC и не наберётся минимальное число
  супер-узлов — оба порога константы в коде, их значения определяются моделированием;
- затем первый период открывается сам; никто не нажимает кнопку;
- чеки, закрытые во время разогрева, монет потом не приносят.

Комиссия с первой сделки делает порог дорогим для подделки: подтолкнуть сеть к старту пустыми сделками стоило бы комиссии с каждой из
них, уплаченной свидетелям, выбранным случайно. Подсчёт оплаченного объёма, а не числа сделок, не даёт тысяче сделок по центу сдвинуть старт. Чеки
разогрева не дают монет, чтобы разогрев не стал самым дешёвым временем для сбора самых ценных монет. Те, кто провёл сеть через разогрев,
сохраняют настоящее преимущество: их полгода накопления (раздел 5.4) идут во время разогрева.

## 5.3 Комиссия сделки

С каждой сделки сеть берёт комиссию в USDC. Её размер — постоянная в коде, определяется моделированием и не выше 5 %; до моделирования —
5 %. Комиссия идёт **свидетелям**: супер-узлам, выбранным случайно для каждой сделки, которые проверяют её чек и подписывают его.
Супер-узел, обслуживший сделку, свидетелем по ней не бывает. Комиссия — это то, что делает фальшивую сделку платной настоящими
деньгами: сделка самому с собой ради чеков стоит комиссии с её суммы, и плательщик не выбирает, кто её получит. Полные правила — в
документе 09.

## 5.4 Правило шести месяцев

Первые шесть месяцев после входа в сеть любой участник может только накапливать монеты: их нельзя продать или передать. Правило
действует для каждого нового участника в любой момент, а не только в первые годы сети. Покупать монеты можно.

```solidity
// Набросок правила: перевод невозможен, пока с момента входа отправителя не прошло шесть месяцев
function _update(address from, address to, uint256 amount) internal override {
    if (from != address(0)) {
        require(block.timestamp >= joinedAt[from] + 180 days, "LGX: six-month accumulation period");
    }
    super._update(from, to, amount);
}
```

Кто пришёл купить и быстро продать, за шесть месяцев не продаст ничего. Кто пришёл работать, продолжает работать, пока срок идёт.

## 5.5 Основатель

Основатель получает 1 % награды каждого периода за создание архитектуры. Доля создаётся вместе с периодом и растёт только тогда, когда
сеть реально работает; заранее не создаётся ни одной монеты.

Каждая порция продаётся не раньше чем через 12 месяцев после своего периода. Блокировка скользящая: у основателя никогда нет большой
суммы, которую можно выбросить на рынок разом. У этой доли нет ключей администратора: её нельзя ускорить, увеличить или отобрать.

```solidity
// Набросок: порция основателя из периода n доступна через 12 месяцев после этого периода
struct FounderTranche { uint96 amount; uint40 issuedAt; }
function releasable(FounderTranche memory t) public view returns (uint96) {
    return block.timestamp >= t.issuedAt + 365 days ? t.amount : 0;
}
```

**Других преимуществ нет.** У основателя нет ни одного преимущества перед любым участником, кроме этой доли. Остальное делает
невозможным код: нет предвыпуска и ключа, который выпускает монеты; нет ключа, который меняет правила; начало выпуска запускает объём, а
не человек; подтолкнуть старт фальшивыми сделками стоит комиссии, которая уходит свидетелям, выбранным случайно.

**Супер-узлов нет.** Основатель и связанные с ним лица, включая Fractera, Inc., не держат супер-узлов и не бывают свидетелями. Они
заранее публично называют свои адреса, и контракты не допускают эти адреса к роли супер-узла и свидетеля; всё, что эти адреса получают,
блокируется на 12 месяцев. Супер-узлы получают комиссию свидетелей и бо́льшую часть выпуска, поэтому основатель, держащий их,
зарабатывал бы на сети сверх 1 %. Контракт видит адреса, а не людей, поэтому связать он может только названные адреса; человека
связывает публичное заявление.

## 5.6 Вход новых супер-узлов

Супер-узел — это постоянный сервер, который хранит индекс поиска, собирает выдачу, помогает агентам соединяться, проверяет и подписывает чеки сделок; сам расчёт выполняет контракт эскроу (документ 04)
(документы 01, 02, 06, 17). Места открываются в три этапа, и каждое место назначается случайным выбором, а не покупается:

- **Места 1–100: без залога.** На старте монет нет, поэтому внести залог нечем. Вместо этого первые награды оператора остаются
  заблокированными как его залог, пока он не достигнет нужного размера, и штрафы берутся из него (документ 06). Льгота принадлежит
  оператору, а не месту.
- **Места 101–1 000: по приглашению.** Эти места открываются независимо от нагрузки сети. Приглашения получают только владельцы
  агентов-исполнителей с оплаченной работой за последний год; один билет на адрес. Залог небольшой, одинаковый для всех и вносится
  монетами, которые заявитель заработал, — он никому ничего не продаёт.
- **После 1 000: по перегрузке.** Новые места открываются, только когда сеть перегружена — сделок на супер-узел больше постоянной, — по
  два места сразу.
- **Измеряют случайные агенты.** Сервер заявителя измеряют агенты, выбранные случайно, а не супер-узлы: действующим супер-узлам
  выгодно, чтобы конкурентов было меньше, поэтому судить новичков должны не они.
- **Случайный выбор с разнообразием.** Места назначаются случайным выбором среди заявителей, чей сервер прошёл проверку, с разнообразием сетей и
  регионов, чтобы один заявитель с множеством серверов не занял много мест. Ранжирование заявителей по мощности или по числу операций не
  используется: оно запустило бы гонку железа и награждало бы нагрузку, созданную самим собой.
- **Ротация.** Раз в 1 год / N, где N — число супер-узлов, выбывает один случайно выбранный супер-узел. Штрафа нет: залог
  возвращается. Его место назначается тем же случайным выбором, на условиях дня, когда оно открылось. В среднем супер-узел остаётся около года,
  поэтому дверь открыта тем, кто делает оплаченную работу сейчас.
- **Минимум качества.** Каждый период случайные агенты проверяют каждый супер-узел по минимуму: прошёл или не прошёл. Прошедшие делят
  поровну 19,8 % награды периода (раздел 5.2); супер-узел, не прошедший несколько периодов, выбывает.
- **Вакансии.** Место, освобождённое ротацией, непрохождением минимума или выбыванием за обман (документ 06), открывается на условиях
  дня, когда оно открылось, и никогда — на условиях ушедшего оператора.

Числа — залог, постоянная перегрузки, сколько непройденных периодов ведут к выбыванию — определяются моделированием. Источник
случайности для выбора мест и ротации и то, как измеряется «прошёл или не прошёл», — открытые вопросы (документ 000).

## 5.7 Чего у $LGX нет

- Нет продажи монет при запуске и нет доли для инвесторов.
- Нет фонда, созданного заранее, и нет ключей, которыми кто-то может создать монеты вне расписания выпуска.
- Нет механизма, единственный смысл которого — цена.
- Нет места в поиске: выдача следует за оплаченной работой, а не за монетами (документ 17).
- Lagrix ничего не обещает о цене $LGX. Это актив её держателя и залог оператора супер-узла.

## 5.8 Почему выпуск $LGX привязан к работе сети

Правила этого документа связывают выпуск монет с оборотом реальных сделок. Связь возникает из самих правил, а не из обещаний.

**Связь через комиссию.** Новые монеты достаются за чеки, а каждый чек — это сделка, с которой удержана комиссия в USDC и уплачена
свидетелям (документ 09). Если стоимость монет, выпускаемых за доллар сделок, становится больше ставки комиссии, появляется выгода
заключать сделки только ради чеков: заплатить комиссию и получить в монетах больше. Таких чеков становится больше, и каждый чек приносит
меньше монет — пока выгода не исчезнет. Поэтому стоимость новых монет, которые сеть выпускает за период, тянется к доле комиссии от
оборота сделок за тот же период:

```
стоимость_монет_выпущенных_за_период ≈ ставка_комиссии × оборот_сделок_за_период
```

**Чего эта связь не делает.**
- Она не задаёт и не удерживает цену на бирже: рынок может отклоняться от неё в обе стороны.
- Отклонение вверх выравнивается медленно: монеты, заработанные новыми участниками, первые шесть месяцев не продаются.
- Отклонение вниз не выравнивает ничего, кроме того, что обслуживать сделки ради монет становится менее выгодно.
- Это свойство правил выпуска, а не гарантия: Lagrix ничего не обещает о цене $LGX.

Точные значения равновесия определяются моделированием сети.
